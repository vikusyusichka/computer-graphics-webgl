# Комп'ютерна графіка та мультимедіа (WebGL)

Лабораторні та контрольна робота з дисципліни «Комп'ютерна графіка та мультимедіа».

Виконала: Фенцик В.Б., група ІМ-41

| Папка | Тема |
|---|---|
| LR1 | Основи створення найпростішої WebGL-програми |
| LR2 | Робота з пристроями введення та організація взаємодії з користувачем |
| LR3 | Робота з проекціями та трансформаціями |
| LR4 | Перспектива та трансформація камери |
| LR5 | Освітлення та затінення |
| LR6 | Затінення поверхонь |
| LR7 | Робота з відображенням текстур |
| LR8 | Проекційні тіні та конвеєр візуалізації |
| KR1 | Контрольна робота №1 |

У кожній папці є код (`index.html`, `main.js`), скріншоти та звіт у форматах DOCX і PDF.

Сторінки відкриваються в браузері. Для LR7 потрібен локальний сервер (наприклад, Live Server у VS Code), бо текстури завантажуються з файлів.
